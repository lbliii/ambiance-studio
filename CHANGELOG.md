# Changes


## 0.8.0

- Added the persistent localhost film library, cross-worktree project registry, movie streaming/seeking, soundtrack choices, version history and synchronized comparison.
- Added immutable delivery registration, explicit current/release selections, exact-version feedback, project overview and generated delivery handoffs.
- Added resumable local iteration recipes over existing revision/render/compose/verification tools, retaining completed outputs and guarding against stale presentation.
- Consolidated current workflow guidance and clarified historical roadmaps.

## 0.7.0 — production, finishing and review

- Added production inventories, reversible scene transactions, source placement, timing tracks, rig proofs, asset preparation and cel previews.
- Added audio sessions, frame rendering, macOS video composition, captured revisions, comparison evidence and edition-bound reviews.
- Added color grading, masked lighting and shared flicker, receiving shadows and reflections, supersampling, sprite-edge inspection and explicit matte repairs, plus reusable look and rig packages.
- Added an interactive look workbench, production fixtures, regression coverage, and locked Node Canvas dependencies for fresh checkouts and CI.
- Updated the six production skills and workflow guidance using the museum project's findings. Working films, generated media and production evidence remain in local project directories.

## 0.4.0 — repository and CLI

Unified JSON CLI for projects, assets, scene operations, checks, reviews and preview. Project initialization can create a blank workspace or isolated Last Lantern template. Scene changes validate and retain restorable snapshots. Project preview serves a selected catalog through explicit read-only routes. Added repository conventions, CLI regression tests and a CI definition. Historical production files are inventoried locally under the ignored archive.


## 0.3.0 — rig and asset workbench

- Added a Pillow compiler for known grids or ordered transparent PNG cels, shared-scale registration, explicit per-cel landmarks, fixed pivots, silhouette estimates, light/dark proofs, playback previews, portable recipes, content cache and protected catalog IDs.
- Added compiled scene snapshots, named sockets, nested layer attachments, per-cel socket tracks, graph validation, inherited transforms/appearance and a rigged Last Lantern example. Existing scene-version-1 files still load. Original art and the original scene recipe remain intact.
- Added socket placement and attachment controls, rotation, full-loop state/pixel inspection, join playback and copyable snapshot reports to the browser workbench.
- Added command-line state/coverage checks with input hashes; 10 compiler tests and 7 rig scenarios supplement the 14 gate tests and 8 legacy engine checks.
- Updated stage skills, contracts, operator guides and the tool strategy. Project initialization records studio version 0.3.0; older project records retain their original version and gate history.

The default editor scene is now `scenes/last-lantern-rigged.json`; import `scenes/last-lantern.json` to inspect the previous placement recipe. The added compiled smoke pack is an inspection study; its source-edge warnings are not silently approved. This release does not add final video export, an audio engine, automatic feature tracking or provider orchestration.

## 0.2.0 — portable studio process

Six local agent skills, stage guides, nine review gates, project initialization, evidence/dependency freshness, and the original placement study. Its earlier validation records remain under `reports/` and the original archive is retained separately.
