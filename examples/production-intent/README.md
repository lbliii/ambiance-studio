# Production-intent CLI replay

Run `python3 examples/production-intent/replay.py FRESH_PROJECT` for local synthetic art, plan application, capture, synchronized raster proof, exact evidence registration and shared readiness checks. Add `--native` on macOS to encode, decode and present both exact silent movie editions through `iteration run`.

The report is `FRESH_PROJECT/reports/production-intent-replay.json` (`format: ambiance-production-intent-replay`, `schema_version: 1`); the full command transcript stays beside it. The replay asserts equal coverage/overview/iteration blockers, rejects a generic nonempty report, rejects reduced final scope, and distinguishes animation evidence from future final movies. The plan explicitly requests a nearly-still fixture and no artistic observation is invented. This is executable structure/raster/native evidence, not PILOT-01 or a completed film.

`tests/test_production_coverage.py` adds wrong-view/revision, modified source/PNG/review, missing art expectation, independent-control spoofing, typed fake movie, legacy behavior and partial presentation checks. Ordinary test fixtures preserve all production originals.
