# Source-backed compound preparation replay

All inputs are locally drawn cleared fixture pixels. No private film or paid tool is used.

```sh
python3 examples/agent-preparation/create_fixture.py work/agent-tea
python3 examples/agent-preparation/create_fixture.py work/agent-cabinet --subject cabinet
```

The script creates the reference art and complete synthetic reconstruction inputs, then runs the public CLI for plan application, preparation init/edit/inspect/build, compiler/admission, source-mapped scene placement and paired proofs. It requires the integrated production-plan and view APIs. `--no-proof` skips raster production for a bounded schema/placement replay.

The tea subject separates a pot, rising lid and fixed front rail; an explicitly reconstructed source supplies hidden body paint. The cabinet reuses the existing botanical fixture, including its known pedestal boundary imperfection. Both include a soft grayscale registration companion, fractional pivots/placement and saved portrait/landscape envelopes. `reports/replay.json` points to the exact preparation receipt, placed scene hash and proofs. `reports/preparation-proof/index.html` links normal/hidden comparisons at full speed; artifact files retain explicit unreviewed status until observations are actually recorded.

The fixture does not establish an autonomous artistic pilot, a complete film, new provider capability or human approval. See [the executable contract](../../docs/AGENT-PREPARATION.md).
