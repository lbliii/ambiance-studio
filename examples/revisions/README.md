# Public CLI revision pilot

Run from the repository with a fresh output path:

```sh
python3 examples/revisions/run_pilot.py --out work/revision-pilot
```

Add `--native` on a macOS host with media-service access to render real H.264 and create two verified sound editions from the same compressed picture. The fixture uses generated geometric test shapes and a quiet diagnostic tone; it is not a film or an artistic sound example.

The pilot uses saved source-coordinate manifests and public CLI commands to place parts, reparent a gesture, compare exact rest pixels, build a rig proof, mix two PCM versions, capture a revision, and check working divergence versus a changed pinned asset. The changed asset is restored in a `finally` block. It preserves all command receipts and a summary in the new fixture project. No production project or paid provider is accessed.

The HTML proof still needs actual browser inspection. The summary explicitly records that running this script alone does not perform a browser, creative, listening or phone review.
