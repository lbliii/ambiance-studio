# CI evidence and workflow replay

Install `python3 -m pip install -r requirements-checks.txt` and `npm ci --ignore-scripts`. The existing Python 3.12/3.14 Linux lanes and Python 3.12/macOS native lane remain supported, with Node 24. `./ambiance test --artifacts NEW_DIR [--require-native]` runs the existing test suite and package audit. Node `tests/test-*.mjs` files are discovered automatically.

The compact result names `run.json`, JUnit, artifact directory and stable failing check IDs. `inputs.json` binds the tracked and unignored source tree; Python cases retain test IDs and bounded details. Each command saves scrubbed stdout/stderr tails (32 KiB each), hashes, original size, truncation, exit status and elapsed time. The run checkpoint persists after each check, so an interrupted process leaves attributable evidence. Timeouts fail and stop the check's process group. Test artifacts do not close production gates.

`--require-native`, also implied by `AMBIANCE_TEST_NATIVE=1`, fails with `CI-NATIVE-UNAVAILABLE` if the actual configured backend is absent. Any skipped test in the required lane fails with `CI-REQUIRED-TEST-SKIPPED`. Discovery remains `available-unexercised`; only the real native tests establish encode/decode results. Do not count a skipped native run as a pass.

CI executes the [public CLI synthetic replay](../examples/workflow-replay/README.md) even after a regression failure. [Scenario records](../tests/agent-evaluations/scenarios.json) separately label unperformed autonomous trials. The replay saves deliberate empty-scope and landscape-only backing failures, actual synchronized raster proofs and restoration evidence; later feature fixtures extend it without duplicating their evaluators.

`python3 tools/ci_bundle.py --run CHECK_DIR --replay REPLAY_DIR --out NEW_UPLOAD_DIR` selects only fixed test-report names, bounded logs and named synthetic proof directories. It rejects symlink escapes and oversized artifacts before copying. Limits are 256 files, 2 MiB per file, 20 MiB total, with a file/hash manifest. CI uploads that directory for seven days on success or failure; it never uploads `projects/`, arbitrary film paths or private media. Expected synthetic diagnostic failures are retained as evidence and labeled by the replay's expected exit code.

Tests inject actual subprocess failure, excess output, timeout, unittest assertion/runtime failure, skipped capability, escaped artifact and oversized bundle. A retained `failure-probe/` also records actual failing subprocesses and their JSON/JUnit/logs; its wrapper passes only if those deliberate failures remain attributable. These exercise the failure path rather than asserting only successful output wording. Source/receiver synchronization, semantic evidence and interrupted paired delivery join the combined replay when their owners' fixtures land. Actual unfamiliar-seed trials, painted held-out calibration, human listening and phone checks remain unperformed unless explicitly recorded.
