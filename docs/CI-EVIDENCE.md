# CI evidence and workflow replay

Install `python3 -m pip install -r requirements-checks.txt` and `npm ci --ignore-scripts`. The existing Python 3.12/3.14 Linux lanes and Python 3.12/macOS native lane remain supported, with Node 24. `./ambiance test --artifacts NEW_DIR [--require-native]` runs the existing test suite and package audit. Node `tests/test-*.mjs` files are discovered automatically.

The compact result names `run.json`, JUnit, artifact directory and stable failing check IDs. `inputs.json` binds the tracked and unignored source tree; Python cases retain test IDs and bounded details. CI records the PR head separately from GitHub's tested checkout/merge SHA, plus run, attempt and event IDs. Each command saves scrubbed stdout/stderr tails (32 KiB each), hashes, original size, truncation, exit status and elapsed time. The Python case report checkpoints the active test and every completed case, and the run checkpoint persists after each check, so an interrupted process leaves attributable evidence. Timeouts fail and stop the check's process group. Test artifacts do not close production gates.

`--require-native`, also implied by `AMBIANCE_TEST_NATIVE=1`, fails with `CI-NATIVE-UNAVAILABLE` if the actual configured backend is absent. Any skipped test in the required lane fails with `CI-REQUIRED-TEST-SKIPPED`. Discovery remains `available-unexercised`; only the real native tests establish encode/decode results. Do not count a skipped native run as a pass.

CI executes the [public CLI synthetic and combined feature replays](../examples/workflow-replay/README.md) even after a regression failure. [Scenario records](../tests/agent-evaluations/scenarios.json) separately label unperformed autonomous trials. The first replay saves deliberate empty-scope and landscape-only backing failures, actual synchronized raster proofs and restoration evidence. The combined runner invokes feature-owned intent, preparation, binding, activity and paired-recovery fixtures without duplicating their evaluators. Portable lanes explicitly omit native recovery; the macOS lane requires it. Completed fixture hashes and source identity are checked before resume.

`python3 tools/ci_bundle.py --run CHECK_DIR --replay REPLAY_DIR --combined COMBINED_DIR --out NEW_UPLOAD_DIR` selects only fixed test-report names, bounded logs and named synthetic proof directories. It rejects symlink escapes and oversized artifacts before copying. Limits are 1,024 files, 2 MiB per file, 20 MiB total, with a file/hash manifest. CI uploads that directory for seven days on success or failure; it never uploads `projects/`, arbitrary film paths or private media. Expected synthetic diagnostic failures are retained as evidence and labeled by the replay's expected exit code. The full local replays retain all input snapshots and proof sequences; the upload is a deliberate diagnostic subset.

Tests inject actual subprocess failure, excess output, timeout, unittest assertion/runtime failure, skipped capability, escaped artifact and oversized bundle. A retained `failure-probe/` also records actual failing subprocesses and their JSON/JUnit/logs; its wrapper passes only if those deliberate failures remain attributable. Combined replay tests verify retained failed attempts, reuse of completed output, tamper rejection and explicit unperformed native cases. Package audit checks the [capability index](CAPABILITIES.json) against registered CLI routes and local references without executing production or planned commands. Actual unfamiliar-seed trials, perceptual calibration, human listening and phone checks remain open unless explicitly recorded against the actual artifacts.
