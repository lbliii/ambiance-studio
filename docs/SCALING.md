# Improve the next film

Use [CLI](CLI.md) as the current command reference and `./ambiance doctor` for local executable capabilities. Detailed behavior lives in the focused scene, asset, audio, revision, finishing and [studio library](STUDIO-LIBRARY.md) contracts. Historical recommendations are preserved in [PROCESS.md](PROCESS.md) and [TOOL-STRATEGY.md](TOOL-STRATEGY.md); they are not a current capability list.

## Current foundation

The toolkit provides source registration, crop/return and matte preparation, cel proofs, rigs and source placement, deterministic shared rendering, local finishing, macOS video encoding/decoding, PCM arrangement, revision-bound evidence, and a project library with current movie selections, comparison, feedback and resumable iteration runs. Automatic image decomposition, feature tracking and paid provider orchestration remain outside the executable toolkit. Full historical Last Lantern effects still require an explicit port.

## Next investments

1. Exercise the whole creation workflow with another operator and a distinct reference. Measure undocumented decisions, unnecessary questions, time to find the current movie, and time to resume work. Engineering fixtures are not a completed independent creative film.
2. Improve reusable rig controls and portable project/media bundles where actual reuse requires them. Protect source identities and accepted versions. Revision hashes do not back up binaries.
3. Add durable provider submission/retrieval and spending controls only within an authorized production scope. Start from observed failures; reconcile uncertain existing requests before resubmitting.
4. Extend rendering/audio backends when measured scene needs justify it. Keep one scene evaluator and compare actual rendered outputs after changes.

Local runs already retain stage progress, recipes and recovery state. The browser library already provides project loading, movie history and comparison. Do not rebuild those as separate orchestration systems. Continue independent reversible work while human reviews remain open; preserve which observations actually occurred.

## Measure useful outcomes

Track generation requests/cost, unknown outcomes and retrieval attempts, preparation effort, reused assets, render duration, review rounds, defects by stage, time to find the movie, and human interruptions. No end-to-end percentage speedup has been established. A rule should solve an observed problem and be reconsidered after another film.
