# Agent asset preparation and recovery handoff

ASSET-01 and OPS-01 provide a public agent authoring path over the existing separation rasterizer, compiler, source placement, canonical production plan and PR #5 saved-view APIs. The executable contracts are [agent preparation](../AGENT-PREPARATION.md) and [provider recovery](../PROVIDERS.md).

Commands: `asset prepare init/inspect/check/edit/build/proof/place` and `asset request record/reconcile/inspect`. A compound preparation retains independent cutouts, fixed foreground, shared backing/removal masks, source-canvas companion masks, fractional pivots and canonical element/inventory bindings. Recipe edits and builds are immutable. Placement prepares idempotent compiler/admission checkpoints, replaces the baked source with clean backing, and saves one normal scene transaction; its journal recognizes a completed placement after interruption. Saved-view proofs retain completed variant hashes and resume local unfinished work. The demonstration motion remains separate from production motion.

The compiler's `preparation_receipt` dependency is verified during build, cache reuse, inspection/admission, scene transactions and revision collection. It pins source/reconstruction/mask/output/mapping dependencies and captured scene/plan/inventory controls. Companion registration is explicit; unsupported independent corrections fail. The proof verifier distinguishes isolated raster evidence from production-scene readiness or actual artistic observations.

The generation ledger records pending/submitted/uncertain/retrieved/selected events without submitting requests. It preserves unknown authority/cost/provider values, hashes actual local image outputs, keeps content-addressed snapshots and idempotent event history, rejects uncertain resubmission, deduplicates returned content and resumes selection after an interrupted write. Legacy ledger rows are preserved.

## Remaining scope

PILOT-01 and FOLLOW-01/02 remain production/evidence work. The source-backed cleared fixture does not complete the measured fresh-painting artistic pilot. The current browser draft editor remains the legacy one-part workbench; compound authoring runs through the CLI. Arbitrary segmentation, generated hidden paint, shear/reflection placement, autonomous provider adapters and arbitrary companion corrections are not implemented. Opaque but incorrect backing requires visual inspection; mask statistics cannot identify its painted semantics. Preparation studies do not close full-scene production expectations or confer approval on catalog admission.
