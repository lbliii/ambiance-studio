# Captured research evidence

This is a compact historical evidence set for the [research report](../report.md), captured against code revision `77ba9f9482b54b7a3074ca48f43682fbdfa978a8`. It contains selected static proof images, exact scene/catalog/recipe snapshots, preparation records and the scripts inspected during the diagnosis. It is not an active production project or an executable reproduction package; the original source artwork and runtime dependencies are not bundled here.

The [manifest](manifest.json) records original source locations, copied-file hashes and capture limitations. Its `snapshot` paths are relative to the research directory containing `report.md`. Original absolute paths inside captured files are historical provenance, not paths to use in a new checkout. Captured files remain byte-for-byte unchanged.

[checks.json](checks.json) records the six targeted suites run during the original audit. [move-diagnostic.json](move-diagnostic.json) records an in-memory geometry experiment, not a raster or motion review. The report distinguishes actual image observations from structural checks and identifies the exact v3/v4 samples supporting each finding. Later pull-request validation is recorded on the pull request, separately from this original audit.
