# Traditional animation tools: preliminary research for Ambiance Studio

September 13, 2026. Local baseline: merged main `08bb56fa191a1c1112e01ca4d964e1f7dd2838b3`, including the [agent-animation vision](../../architecture/AGENT-ANIMATION-VISION.md). This pass compares primary documentation with the studio's contracts, implementation and a small executed CLI probe. It does **not** report hands-on trials of the external applications, production-quality animation, or a selected replacement backend. The 3D-character reconstruction idea is outside this pass.

## Recommendation

Start with **Harmony and OpenToonz for exposure authoring**, **TVPaint and Krita for painted drawing revision**, and **Storyboard Pro and Open RV for editorial changes and dailies**. Study Moho's control/action design when shaping reusable performances. Treat Blender/Grease Pencil as a bounded integration candidate and OpenTimelineIO (OTIO) as an editorial interchange candidate.

The evidence supports building animator-facing operations over our existing native state. We already have registered cels, drawing selection, deterministic seeking and recoverable scene transactions. The immediate work is making exposure boundaries, frame addressing, retiming scope and observation inputs explicit. Whether to use an external renderer remains an experiment; this research establishes neither a need to replace ours nor that ours is sufficient for finished acting.

The most consequential local findings are:

- Separate keys displaying the same cel survive save/reload, but `scene timing` merges them into one reported hold. A rendered hold is insufficient to reconstruct editing boundaries.
- A normal `scene apply` batch can replace a drawing over exactly six output frames while preserving later frames and a restorable prior scene. The missing authoring convenience should reuse this transaction.
- **An exact-frame defect is reproducible at 24 fps:** a cel key at frame 1 selects the previous cel when sampled at `1/24` seconds. Wrapping changes the floating-point value before the key comparison. Frame-addressed authoring needs an engine-level regression case before it can promise exact exposure.
- The current scene clock remains circular. Extending duration does not perform a ripple edit, stretch keys or retime sound.

These are findings for existing owners, not completed work packages. The [alignment map](../../architecture/STUDIO-PLAN-ALIGNMENT.md) and [first-short packages](../../architecture/FIRST-SHORT-WORK-PACKAGES.json) remain authoritative.

## What to learn from each tool

All external capabilities below are **documented**, not locally executed. Version labels identify the documentation inspected, not a claim about the newest installed release. Proposed studio applications are our inferences.

| Tool / documentation | Useful convention and evidence | Fit with our organization; preliminary decision |
| --- | --- | --- |
| **Harmony 24** | A drawing and its exposure boundary are different concepts. A key exposure can start a new block even when the drawing stays the same; later substitution stops at that boundary. The drawing picker also makes the selected drawing inspectable. [Key exposures](https://docs.toonboom.com/help/harmony-24/essentials/cut-out-animation/about-key-exposure.html), [drawing substitutions](https://docs.toonboom.com/help/harmony-24/premium/reference/view/drawing-picker-view.html). | **Adopt convention, P15/P02.** Keep named drawing identity in the character/model owner and exposure boundaries in canonical timing. Derive an X-sheet from that state. Our probe proves raw equal-value keys can be retained; it does not prove a semantic substitution command exists. |
| **OpenToonz 1.7.1 manual** | A level contains drawings; Xsheet cells expose those drawings at scene frames. Loaded drawings remain available even when not exposed. The horizontal timeline and vertical Xsheet edit the same scene, and nested scenes appear as Sub-Xsheets. [Xsheet/Timeline](https://opentoonz.readthedocs.io/en/latest/working_in_xsheet.html). | **Adopt vocabulary and inspect scripting, P00/P03/P15.** Separate drawing identifiers from exposure positions and library availability from shot use. Our atlas index is a runtime selection, not a suitable permanent character-drawing name. Nested editorial time belongs with P03/P05, not model mounting. |
| **TVPaint current web manual** | Instances contain images in animation layers. Its workflow splits timing to insert in-betweens. Pre/post behavior is explicit per layer: none, loop, ping-pong or hold. [Instances](https://doc.tvpaint.com/docs/animation-first-steps/instances/instance-concept), [workflow](https://doc.tvpaint.com/docs/animation-first-steps/instances/introduction), [pre/post behavior](https://doc.tvpaint.com/docs/animation-additional-functions/timeline-options/pre-post-behavior). | **Adopt painted workflow, P02/P03/P15.** Keep art preparation separate from exposure editing. Distinguish a held last drawing from a repeating local action and from the shot's end. TVPaint's word “instance” describes an image container here; it must not overwrite our reusable-model instance vocabulary. |
| **Krita 5.3 manual** | Cloned frames share image data; duplicated keyframes have independent copies. Timing edits and drawing edits therefore have different propagation. Frame-by-frame animation and onion skins support painted revision. [Timeline](https://docs.krita.org/en/reference_manual/dockers/animation_timeline.html), [animation](https://docs.krita.org/en/user_manual/animation.html). | **Adopt edit distinctions and drawing review, P02/P15.** “Expose again,” “make an independent drawing” and “revise the shared source” need different semantics. Preserve source/registration recipes and accepted versions. Neighboring output frames may show the same hold, so also inspect neighboring distinct drawings. |
| **Moho Pro 14** | Smart Bones connect an authored action to a control, including expression/turn controls. Switch selection and channel timing support controllable 2D performance. These are authored behaviors; a control does not establish missing artwork. [Vendor features](https://moho.lostmarble.com/pages/features). | **Adopt control/action separation, P02/P03 and model owners.** Prefer a small useful control vocabulary over manipulating every layer. Current local construction exposes static controls/compatible drawings; it does not yet supply timed reusable actions. Prove one turn/blink/reaction with existing primitives before adding deformation or a constraint system. |
| **Storyboard Pro 24** | Normal panel-duration edits ripple later panels; Animatic Editing Mode can change in/out points while leaving other material in place. Marker ripple is separately controlled. [Editing modes](https://docs.toonboom.com/help/storyboard-pro-24/storyboard/timing/about-animatic-editing-mode.html), [markers](https://docs.toonboom.com/help/storyboard-pro-24/storyboard/timing/edit-marker.html). | **Adopt explicit editorial scope, P01/P03/P04/P05.** “Delay the reaction” must state whether to consume an existing hold, move selected performance/cues, or move subsequent shots. Preflight the affected ranges and audio. Our `scene clock` is a duration transaction, not an editorial operation. |
| **ASWF Open RV 4.0 manual** | Saved sessions retain source references, cut ranges and review state. Sequence-global frame positions differ from source-relative cut frames. Session references alone do not freeze changing media. [Sessions](https://aswf-openrv.readthedocs.io/en/latest/rv-manuals/rv-user-manual/rv-user-manual-chapter-five.html), [file format](https://aswf-openrv.readthedocs.io/en/latest/rv-manuals/rv-reference-manual/rv-reference-manual-chapter-six.html). | **Adopt review conventions; consider export, P05/P06/P16.** Extend our exact revision/edition/movie bindings with explicit sequence-to-shot-to-source frame mapping. Reuse feedback records. A future RV session export should refer to captured media and carry identity mapping; it is not itself an observation or a new review authority. |
| **Blender / Grease Pencil manual** | Drawing timing is editable in the Dope Sheet. Onion skins can select nearby frames, keyframes or selected keys. Background rendering is documented. [Drawing timing](https://docs.blender.org/manual/en/latest/editors/dope_sheet/modes/grease_pencil.html), [onion skins](https://docs.blender.org/manual/en/latest/grease_pencil/properties/onion_skinning.html), [command-line render](https://docs.blender.org/manual/en/latest/advanced/command_line/render.html). | **Adopt inspection choices; defer backend decision, P05/P15.** Use frame-neighbor versus drawing-neighbor modes over our shared sampler. A Blender trial should measure painted-source fidelity, alpha, registration, deterministic seeking and actual background operation before any integration commitment. This is a 2D workflow study. |
| **OpenTimelineIO 0.18.0** | An editorial API/interchange format for clips, tracks, timing, transitions and metadata; media is external. Source/available/parent ranges and marker coordinates are distinct, with explicit exclusive-end helpers. [Overview](https://opentimelineio.readthedocs.io/en/v0.18.0/), [time ranges](https://opentimelineio.readthedocs.io/en/v0.18.0/tutorials/time-ranges.html). | **Evaluate a narrow adapter, P03/P05/P06.** Compare a native cut list with OTIO before inventing interchange. Export derived editorial data while native shots/cues remain authoritative. OTIO does not supply our cel evaluator, character controls, rendering or media integrity checks. |

## Executed local observations

Run from the repository root, with the existing Python/Node environment:

```sh
node docs/research/animation-tools-2026-09-13/probe.mjs > /tmp/animation-tools-observations.json
```

The [probe](probe.mjs) creates a fresh temporary blank project, seeds a clearly synthetic metadata-only scene/catalog, and then uses public CLI operations for edits and timing. It uses the shared evaluator for frame comparisons. It never registers production art or changes a working film. The retained temporary path is printed to stderr. The [checked-in observations](local-observations.json) contain the baseline commit, relevant source hashes, probe hash, exact command arguments/exit codes and observed values.

| Probe | Observed result | Implication |
| --- | --- | --- |
| Save keys at 0 and 0.5 seconds selecting cel 0, then select cel 1 at 1 second | Both keys persist; the timing report gives one cel-0 hold from 0 to 1 | Expose editing boundaries separately from visible holds. This is a diagnostic limitation, not data loss in saved tracks. |
| Substitute cel 3 over `[0.25, 0.5)` at 24 fps | Only zero-based output frames 6–11 change; frame 12 resumes cel 0. Dry run leaves bytes unchanged and the applied transaction keeps its prior snapshot | The native transaction can execute a bounded change; no new mutation engine is needed. |
| Author frame keys 0, 1, 3, 5, 48 in a two-second, 24-fps loop | At frame 1 the intended cel is 1 but the sampled cel is 0. Other sampled frames in this specimen match | **Open defect:** `1/24` is `0.041666666666666664`, but `wrapTime(1/24, 2)` is `0.04166666666666652`; the strict comparison falls below the key. P03 should own the shared correction and frame-boundary regression; P15 must exercise it. No fix is included. |
| Supply a nonclosing cel track; separately change only the loop length from 2 to 4 | Both dry runs fail without changing the scene: closure and exact endpoint are required | Current loop constraints are real. Finite duration and retiming cannot be obtained by relabeling `scene clock`. |
| Sample at duration and start; seek out of order and revisit | Endpoint equals start; revisited sampled state is identical | Existing deterministic seeking is useful for inspection. This establishes geometry/cel state only, not pixel fidelity, motion quality or listening. |

An exit code of zero means the research probe completed; it is **not** an all-green timing acceptance test. Inspect `mixed_exposures.all_requested_frame_selections_match` (false in this run). No external application comparisons, raster playback or vision-model observations were performed. No capability or package status changes follow from these results.

## Bounded next studies within the existing roadmap

Use one supplied-art 8–12-second passage: notice a cue, hold a reaction, turn, speak, pick up a prop. It is a mechanics/acting calibration within the full-minute pilot, not a smaller replacement deliverable. Use the same artwork, intended performance, output fps and directing notes when comparing tools.
