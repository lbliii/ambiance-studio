# Prepare production assets

Inspect `plan next`, source ledger, selected compositions and existing asset/scene identities. Use `library find/inspect` before making replacements. Prepare the independent cutouts, backing, masks and cels selected actions need, then present key poses and contextual proof. Read [asset workflow](../../../docs/workflows/02-assets-and-cels.md) for stage details.

Choose reuse, derivative edit or authorized generation for each part. Inspect reference art before creative edits and use the host's image skill/tool when applicable. Preserve raw originals and versioned production derivatives. `asset request record/reconcile/inspect` tracks provider request identity and selected results; a timeout is uncertain, so recover existing output before another charged request. Missing art remains explicit work rather than silently reduced scope.

Size sources for their largest displayed footprint across views and motion, tracing native detail through crop/registration and enlargement. High output dimensions or supersampling do not recover missing paint. Use the workflow's source-detail checks and existing full-resolution proofs; planned TV profiles and automatic audits are not available commands.

Lock cel framing, palette, stable geometry, pivot and sequence scale. Show changing drawings separately from interpolation, holds and brightness modulation. Inspect an earlier film's actual assets/use before adopting its method. A prompt cannot guarantee transparency, registration or a seamless loop.

Use `asset preflight`, then mapped `asset crop/return` for repairs; see [raster preparation](../../../docs/ASSET-PREPARATION.md). Compound subjects use `asset prepare init/inspect/check/edit/build/proof/place` with shared backing and independent fixed occluders; see [agent preparation](../../../docs/AGENT-PREPARATION.md). Bind prepared parts to the canonical element/inventory part and every intended view. Follow [whole-object ownership and proof](../../../docs/LAYER-AND-LIGHT-PLANNING.md#whole-object-ownership-and-proof): prepare the complete subject before animated subparts, clear its whole footprint from other layers, and preserve separate surroundings/occluders. Missing body or backing remains required work. Keep source mappings, masks, sockets and unlit geometry where needed.

Use `asset build/inspect/proof/admit` for immutable registered packs. `asset trim-cels` prepares a common crop with remapped geometry and static/per-cel sockets; review dependent masks/receivers before adoption. [Production operations](../../../docs/MIDNIGHT-OPERATIONS.md) covers this path and `plan fulfill` for hashed stage/file/asset/layer evidence. Fulfillment cannot alter scope or pass an artistic review.

Inspect whole-object isolation/removal, contacts, edges, meaningful poses, internal rest/extremes and full-speed playback in each intended view. Catalog admission establishes availability, not approval. Close assets only with actual files, source/recipe evidence and observations; an opaque checkerboard atlas is not a usable alpha asset.
